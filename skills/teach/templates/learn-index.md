# Learn — Session Index

Every `/teach` session, by subject, with its spaced-review date. Updated at the end of each session.

This file is what turns a pile of transcripts into a curriculum. `/teach --due` reads it to find
reviews that have come due, and the tutor reads it at the start of a new session — prior work in an
adjacent subject is free probe data, and it is what makes interleaving across subjects possible at
all (`pr_interleaving_and_spacing`).

`Revisit on` is set per `ctd_spacing_is_the_scheduling_lever` — a gap of roughly 10–20% of the
intended retention interval. That is a memory mechanism, not a rest mechanism; do not read a due date
as a rest day.

Brier figures here are per session. **Do not average them across subjects** — see PROTOCOL rule 10.
